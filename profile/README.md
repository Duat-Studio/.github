## 🛠️ Technology Stack & Engineering Standards

- 🦀 **Native Systems Performance**: Built with **Rust** and **Tauri 2.0** for minimal RAM overhead (~40–80 MB footprint) and native OS process isolation.
- 🎨 **Modern Design Systems**: GPU-accelerated **React + CSS Dark Glassmorphism** with custom dual palettes (Antique Gold `#C9A227` & Nile Teal `#0E7C86`).
- 🔒 **Cryptographic Vault Security**: Built-in **SHA-256** salted hashing and **AES-256-GCM** binary database encryption.
